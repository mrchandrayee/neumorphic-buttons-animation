A collection of soft neumorphic button animations with pressed states and depth illusions. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🫙 Soft neumorphic pressed depth effect
- 🎛️ Multiple button variants
- ✨ Smooth box-shadow transitions
- ♿ Accessible focus states
- ⚡ Zero dependencies
